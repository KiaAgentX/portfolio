9Router چیست و چرا بهش نیاز داری؟

هسته مرکزی سیستم — مدار همه پروایدرها از اینجا رد می‌شود

9Router یک روتر (Gateway) محلی و متن‌باز است که بین ابزارهای کدنویسی‌ات (Cursor، Claude Code، Cline، Codex و…) و ده‌ها پروایدر AI می‌نشیند و همه را پشت یک Endpoint سازگار با OpenAI در می‌آورد: http://localhost:20128/v1

بدون آن معمولاً با این‌ها روبه‌رو می‌شوی: تمام‌شدن سهمیه وسط کار، جابه‌جایی دستی بین چند اکانت، سوختن توکن روی خروجی git diff و لاگ‌ها، و تنظیمات جداگانه برای هر ابزار. با 9Router همه از یک نقطه کنترل می‌شود: اول اشتراک‌هایت مصرف می‌شوند، بعد مدل‌های ارزان، و در نهایت مدل‌های رایگان.

علاوه بر این، 9Router یک پلتفرم چندرسانه‌ای است: Embedding، تولید تصویر، تبدیل گفتار، جستجوی وب و بسیاری قابلیت‌های دیگر را در اختیار ابزارهای شما قرار می‌دهد.

Providers

Media Providers — سیاره چندرسانه‌ای

فراتر از متن: تصویر، صدا، جست‌وجو

9Router صرفاً روتر متنی نیست؛ یک پلتفرم کامل چندرسانه‌ای است که تمام نیازهای رسانه‌ای ابزارهای شما را پوشش می‌دهد:

Embedding

OpenRouter، NVIDIA NIM، Voyage AI، OpenAI، Jina AI و مدل‌های Self-hosted. قابلیت تولید بردارهای متنی برای جستجوی معنایی.

Text to Image

مسیردهی درخواست‌های تولید تصویر بین مدل‌های سازگار مانند DALL‑E، Stable Diffusion و Flux.

Speech to Text / TTS

تبدیل صوت↔متن با سرویس‌های محلی (Whisper) و ابری (OpenAI، ElevenLabs).

Web Fetch & Search

جست‌وجوی وب و دریافت محتوای صفحات برای تقویت پرامپت. پشتیبانی از موتورهای جستجوی مختلف.

Proxy Pools & Skills

استخر پروکسی برای چرخش IP و مهارت‌های سفارشی ایجنت‌ها (ابزارهای خودکار).

Console Log & 9Remote

لاگ زنده درخواست/پاسخ و کنترل از راه دور اینستانس‌های 9Router در شبکه.

نصب و راه‌اندازی

پرتاب به مدار — سه مسیر فرود

پیش‌نیاز: Node.js نسخه ۱۸ یا بالاتر.

npm install -g 9router
9router

داشبورد خودکار روی http://localhost:20128/dashboard باز می‌شود.

docker run -d --name 9router -p 20128:20128 \
  -v "$HOME/.9router:/app/data" \
  -e DATA_DIR=/app/data \
  decolua/9router:latest
git clone https://github.com/decolua/9router.git
cd 9router && npm install && npm run build

export JWT_SECRET="super-secure-jwt-key"
export INITIAL_PASSWORD="strong-admin-password"
export DATA_DIR="/var/lib/9router"
export PORT="20128"
export HOSTNAME="0.0.0.0"
export REQUIRE_API_KEY="true"

npm install -g pm2
pm2 start npm --name 9router -- start
pm2 save && pm2 startup

برای کاربران macOS با Homebrew:

brew tap decolua/9router
brew install 9router

سیستم Fallback سه‌لایه

وقتی یک سیاره پشت خورشید می‌رود، بعدی می‌درخشد
Tier 1 — اشتراک

Claude Code، Codex، Copilot، Gemini و اشتراک‌های پولی. اول این‌ها مصرف می‌شوند. هزینه‌ها ثابت و ماهانه است.

Tier 2 — ارزان

GLM، MiniMax، Kimi و مدل‌های pay-as-you-go. با اتمام Tier 1 خودکار فعال می‌شود. هزینه هر درخواست بسیار پایین است.

Tier 3 — رایگان

Kiro، OpenCode Free، Qwen — آخرین لایه پشتیبان، تقریباً هیچ‌وقت قطع نمی‌شود. محدودیت‌های روزانه دارند.

در داشبورد می‌توانی Combo بسازی و ترتیب مدل‌ها را دستی مشخص کنی، مثلاً: cc/claude-sonnet → glm/glm-4 → kr/claude-sonnet

بهینه‌سازی توکن: RTK و Caveman Mode

کم‌کردن جرم بدون از دست‌دادن مدار

🚀 RTK Token Saver

خروجی ابزارهایی مثل git diff، grep، ls و درخت فایل را خودکار فشرده می‌کند و معمولاً ۲۰–۴۰٪ از توکن ورودی کم می‌کند. برای پروژه‌های بزرگ، این عدد می‌تواند به ۶۰٪ هم برسد.

فعال به‌صورت پیش‌فرض

🪨 Caveman Mode

حالت فشرده‌سازی پاسخ مدل؛ می‌تواند تا ۶۵٪ از توکن‌های خروجی را ذخیره کند — مخصوصاً برای پاسخ‌های طولانی. با استفاده از خلاصه‌سازی هوشمند، کیفیت پاسخ را حفظ می‌کند.

قابل فعال‌سازی در داشبورد

مثال عددی: یک git diff با ۵۰۰ خط، حدود ۴۰۰۰ توکن مصرف می‌کرد. با RTK به حدود ۲۴۰۰ توکن کاهش می‌یابد (۴۰٪ صرفه‌جویی). در یک ماه با ۱۰۰ درخواست مشابه، بیش از ۱۵۰۰۰۰ توکن ذخیره می‌شود.

نکات پیشرفته

مدارهای دوردست برای کاربران حرفه‌ای

دسترسی از بیرون (VPS)

اگر می‌خواهی روی موبایل یا سیستم دیگر به 9Router دسترسی داشته باشی:

# با Docker روی سرور
docker run -d --name 9router -p 20128:20128 \
  -v /root/.9router:/app/data \
  -e DATA_DIR=/app/data \
  decolua/9router:latest

# سپس با Cloudflare Tunnel یا reverse proxy امن‌سازی کن
# مثال با Cloudflare Tunnel:
cloudflared tunnel --url http://localhost:20128

چند اکانت برای یک پروایدر

می‌توانی چند اکانت برای یک پروایدر اضافه کنی؛ 9Router به‌صورت round-robin و با failover بین آن‌ها جابه‌جا می‌شود. این ویژگی برای مدیریت سهمیه‌های محدود بسیار مفید است.

استفاده از Webhook برای اعلان‌ها

می‌توانی برای رویدادهایی مانند اتمام سهمیه، خطا یا تغییر پروایدر، Webhook تنظیم کنی تا به تلگرام، دیسکورد یا ایمیل اعلان ارسال شود.

عیب‌یابی

وقتی سیاره از مدار خارج می‌شود
خطا / مشکلعلت ریشه‌ایراه‌حل
401 Unauthorizedنقص در Bearer Token یا انقضای نشست.ورود مجدد به داشبورد و تنظیم صحیح API Key. از بخش Keys یک کلید جدید بسازید.
429 Rate Limitاتمام سهمیه مدل اولیه.بررسی عملکرد Fallback و Combo. مطمئن شوید که Tier 2 و 3 به درستی تنظیم شده‌اند.
اتصال ابزار برقرار نمی‌شودBase URL یا پورت اشتباه.مطمئن شو 9Router در حال اجراست و آدرس دقیقاً http://localhost:20128/v1 است. همچنین فایروال را بررسی کنید.
مدل موردنظر در لیست نیستپروایدر مربوطه هنوز متصل نشده.از داشبورد بخش Providers را بررسی و اتصال را کامل کن. اگر پروایدر پشتیبانی می‌شود، آن را اضافه کنید.
خطای CORS در مرورگرتنظیمات CORS در 9Router.در فایل پیکربندی cors.origin را تنظیم کنید یا از پروکسی معکوس استفاده کنید.

سوالات متداول

پرسش‌های رایج ساکنان منظومه

آیا کاملاً رایگان است؟

خود نرم‌افزار 9Router رایگان و متن‌باز (MIT) است؛ هزینه فقط مربوط به پروایدرهایی است که استفاده می‌کنی. با Tier 3 می‌توانی تقریباً رایگان کار کنی.

روی ویندوز کار می‌کند؟

بله؛ با Node.js یا Docker روی ویندوز، مک و لینوکس اجرا می‌شود.

داده‌هایم کجا ذخیره می‌شود؟

محلی روی سیستم خودت، معمولاً در مسیر ~/.9router. امکان فعال‌سازی cloud sync هم وجود دارد.

چطور مدل‌های موجود را ببینم؟

curl http://localhost:20128/v1/models

با Aider یا OpenWebUI هم کار می‌کند؟

بله؛ هر ابزاری که از OpenAI-compatible API پشتیبانی کند، با تغییر Base URL به http://localhost:20128/v1 کار می‌کند.

آیا می‌توانم از 9Router در تیم استفاده کنم؟

بله؛ با نصب روی VPS و تنظیم JWT_SECRET و REQUIRE_API_KEY، چندین کاربر می‌توانند به یک اینستانس متصل شوند.
