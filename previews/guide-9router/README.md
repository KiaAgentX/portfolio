# 9Router — مرجع کامل فارسی

راهنمای جامع 9Router: نصب، پروایدرها، Fallback سه‌لایه، Media Providers و بهینه‌سازی توکن — با رندر سه‌بعدي.

## Kit

- HTML
- Three.js
- Tailwind CSS
- Font Awesome

## اجرا

```bash
# مستقیم در مرورگر باز کنید، یا:
python -m http.server 8000
```

> تک‌فایل آموزشی؛ احتمالاً نیازمند اتصال اینترنت برای CDN.
