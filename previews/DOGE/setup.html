📦 General

1 What is DOGE Vault Premium?
It's a complete offline Dogecoin trading simulator with 9 difficulty levels, Pattern Scanner, Musk Mentor, and full PWA support.
2 Is it free?
The core simulator is free to use locally. The full Premium package includes all 9 versions and advanced features.
3 Do I need an internet connection?
No. Once loaded, the entire app runs 100% offline via service worker. Internet is only needed for the initial download.
4 Where is my data saved?
All data is stored in your browser's localStorage. It stays on your device only. Nothing is sent anywhere.
5 Can I use this on my phone?
Yes! Open in Chrome/Safari → tap "Add to Home Screen" → install as a PWA. Works offline.
6 Which version should I start with?
Start with Easy if you're new, then move to Normal and Hard as you gain confidence.
7 How do I reset everything?
In Dashboard → Settings tab → click "Reset Everything". Or delete localStorage manually via browser dev tools.
8 Is this safe? Does it track me?
Yes, it's completely safe. No tracking, no analytics, no external servers. All data stays on your device.
9 What is the difference between Dashboard and Journal?
Dashboard is for trading (buy/sell, charts, XP). Journal is for tracking (log trades, filters, export, analytics).
10 Can I export my data?
Yes. In Journal → Export CSV or JSON. In Dashboard → Settings → Export CSV/JSON.

📥 Installation & Setup

11 How do I install the PWA?
Open the page in Chrome/Safari → tap the share button → "Add to Home Screen". The app will open standalone.
12 I don't see "Add to Home Screen" on iPhone.
Use Safari, not Chrome. Tap the Share button (box with arrow) → scroll down → Add to Home Screen.
13 Can I run this without Python?
Yes. You can use any static server (Node.js, VS Code Live Server, or upload to Netlify/GitHub Pages).
14 What is the command to start Python server?
Open terminal in the project folder and run: python3 -m http.server 8000. Then open http://localhost:8000.
15 How do I find my local IP address?
On Linux/macOS: ip addr. On Windows: ipconfig. Look for 192.168.x.x.
16 Can I host this on GitHub Pages?
Yes. Upload all files to a GitHub repo → Settings → Pages → select branch main → enable. Your URL will be https://username.github.io/repo-name/.
17 Does Netlify support PWA?
Yes. Drag and drop your folder to Netlify. PWA features work automatically because manifest.json and service-worker.js are in the root.
18 What about Vercel?
Yes, Vercel works the same way. Run vercel in your project folder and follow the prompts.
19 Can I use this on Android with Termux?
Yes. Install Termux, run pkg install python, then python3 -m http.server 8080. Access from any device on the same network.
20 Is there a Docker version?
Yes. Create a Dockerfile with FROM nginx:alpine and COPY . /usr/share/nginx/html. Build and run: docker run -p 8080:80 doge-vault.

📈 Trading & Strategies

31 What is the recommended leverage?
Start with 10x. You can adjust from 1x to 150x in the Trade Panel.
32 What is the best risk percentage?
1%–2% per trade is recommended. Use the quick risk buttons (1%, 2%, 5%) for easy adjustment.
33 How do I set a Stop Loss and Take Profit?
Enter the price in the SL and TP fields in the Trade Panel before opening a position. The system will close automatically when hit.
34 How does the trailing stop work?
Enable "Trailing" in the Trade Panel. The stop loss will move up (for long) or down (for short) as price moves in your favor.
35 Can I backtest my strategies?
Yes. In the Dashboard, click "Run Backtest" – choose Quick (10 candles) or Full (50 candles) test.
36 What is the Strategy Library?
In the Pro Journal, you can save your custom strategies with name and rules. Tag trades with your strategy name.
37 What is the difference between Limit and Stop orders?
Limit: buy below market / sell above market. Stop: buy above market / sell below market. Both are pending orders.
38 How do I use OCO for breakout trading?
Set a buy order above market (for upward breakout) and a sell order below market (for downward breakout). The first one triggered cancels the other.
39 What is the best timeframe for scalping?
1s to 15s timeframes are ideal for scalping. Use the shortcut keys 1-5 to switch instantly.
40 How do I read the order book?
The order book shows bid (green) and ask (red) prices with volume. The spread is the difference between highest bid and lowest ask.

🔧 Troubleshooting

41 The page is blank. What should I do?
Open the browser's developer console (F12) to check for errors. Ensure all files are in the same folder.
42 PWA won't install. Why?
Ensure you are opening the page via http:// (not file://). Verify manifest.json and service-worker.js exist in the root folder.
43 Data is not saving. What's wrong?
Do not use Incognito/Private mode. localStorage is disabled in private mode. Check that your browser allows localStorage.
44 I can't connect from my phone to my computer.
Ensure both devices are on the same Wi-Fi. Check your firewall settings and allow port 8000. Use the correct IP address (not localhost).
45 Import Config failed. What should I do?
Make sure doge-config.json is in the same folder as the HTML files. Open Settings → Import Config → select the file.
46 The chart is not updating.
Check if you have JavaScript enabled. Refresh the page. If using a mobile browser, try Chrome or Safari.
47 Why are the Fibonacci levels not showing?
Fibonacci levels are auto-drawn on the chart. If there isn't enough range, they may appear clustered. Zoom out.
48 The Scanner shows "—". Is it broken?
No. "—" means no pattern detected. Wait for price action to form a pattern. Scanner updates every 1-2 seconds.
49 I closed a trade but the position box still shows data.
Click the "Close" button again or refresh the page. The position should clear after a successful close.
50 Why is my balance not updating after a trade?
Balance updates after a trade is closed (not while open). Check the History tab for the closed trade record.
