cPanel launch checklist

      
Follow in order. Everything is plain static hosting — no database, no build step.

    

    
    
      
  • In cPanel File Manager, open public_html and upload the contents of the public_html folder from the zip (index.html, biz.css, biz.js, config.js, sw.js, manifest.webmanifest, assets/, .htaccess).
    • 
      
  • Run this page locally, edit your details, then upload the downloaded config.js over the existing one.
    • 
      
  • Enable HTTPS: cPanel → SSL/TLS Status → Run AutoSSL. The install prompt and service worker require HTTPS.
    • 
      
  • The bundled .htaccess already forces HTTPS, sets caching, compression and correct MIME types — no edits needed.
    • 
      
  • Verify: open the site, check the countdown, switch languages from the language menu, and install the app from the browser menu.
    • 
      
  • Keep this setup.html and the zip outside public_html. It is for internal use only.
