Railway چیست؟

Railway یک پلتفرم استقرار ابری است که اپلیکیشن‌ها را در چند ثانیه به صورت آنلاین درمی‌آورد. بدون نیاز به مدیریت سرور، Docker یا Kubernetes.

⚡

استقرار یک‌کلیکی

کدت را بفرست، Railway بقیه را انجام می‌دهد. Node.js، Python، Go، Docker — همه پشتیبانی می‌شوند.

🗄️

دیتابیس آماده

PostgreSQL، MySQL، Redis، MongoDB — با یک کلیک اضافه شوند. نیاز به تنظیم ندارند.

🔗

اتصال GitHub

هر push به main = deploy خودکار. Pull Request = محیط preview. مثل جادو.

📊

مانیتورینگ زنده

CPU، RAM، ترافیک و لاگ‌ها را لحظه‌ای ببین. نیاز به Grafana یا Datadog نیست.

🌐

دامنه رایگان

هر اپ یک زیردامنه .up.railway.app می‌گیرد. دامنه اختصاصی هم با SSL رایگان.

💰

فقط چیزی که مصرف می‌کنی پرداخت کن. بدون قرارداد، بدون هزینه پنهان.
