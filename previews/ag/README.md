# DropAgentX — راهنمای ساخت AI Agent

مقاله بلند فارسی: «برای ساخت AI Agent باید برنامه‌نویسی بلد باشی؟» — پاسخ عمیق و کاربردی همراه با پازل ۱۰۰ فیچر گیت‌هاب، چت‌بات چند-پروایدر، ماشین‌حساب هزینه و کوییز سطح‌سنجی.

## Kit

- HTML
- Three.js
- Google Fonts

## اجرا

```bash
# مستقیم در مرورگر باز کنید، یا:
python -m http.server 8000
```

> تک‌فایل تعاملی؛ رندر سه‌بعدی بخش‌ها با Three.js.
