🌐 Local & Cloud Hosting — run anywhere

11 platforms

Choose your platform below for step‑by‑step instructions. From local development to global deployment, every option is covered.

🐍 Python (any OS)
1. Open terminal in the project folder.
2. Run python3 -m http.server 8000
3. Open browser to http://localhost:8000
4. On phone, use http://[your-ip]:8000
✅ Works on Windows, macOS, Linux, Android (Termux), iOS (iSH).
💡 Local IP: ip addr (Linux/macOS) or ipconfig (Windows).
💡 Firewall: Allow port 8000 on your OS firewall for local network access.

❓ FAQ — first‑time user

common questions
🤔 I've never used Pyhub before. Where do I start?

Open Online (Workshop) → browse commands → try the Workshop tab to write and run Python code. Or use Offline (Reference) to just browse and copy commands. Both are beginner-friendly.

📚 What's the difference between the two versions?

Online includes an interactive Python workshop with live code execution (requires internet for first load). Offline is a pure reference mode – all commands available offline, no internet needed after first visit.

🏆 How do I unlock trophies?

Just use the app! Each achievement unlocks automatically when you hit the requirement. For example: First Command → open any command. First Favorite → star a command. You'll see confetti and a toast when you unlock one.

📱 Can I use this on my phone?

Yes! Both versions are mobile-responsive and PWA-ready. Open in Chrome/Safari → tap "Add to Home Screen" → install as an app. Works offline.

💾 Where is my data saved?

All data (favorites, visited, ratings, workshop progress) is saved in your browser's localStorage. It stays on your device only. Nothing is sent anywhere.

🔄 How do I reset everything?

Click the 🔄 Reset All button in the stats bar above. Or delete localStorage manually via browser dev tools.

🧪 What if the workshop doesn't load?

The online version uses Pyodide (Python in the browser). First load may take 2-5 seconds. If it fails, try refreshing or check your internet connection. After first load, it works offline.
