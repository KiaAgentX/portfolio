Prerequisites

0 Install Python 3.9+

Download from python.org. During installation, check "Add Python to PATH".

python --version   # Should show 3.9 or higher

Option 1: Local Setup (Recommended)

Windows

1 Clone the repository

git clone https://github.com/ImXforever/fly-gold-trader.git
cd fly-gold-trader

2 Run setup

# Double-click setup.bat in file explorer, OR:
setup.bat

# To auto-start after install:
setup.bat --run

3 Open dashboard

http://127.0.0.1:5000

Linux macOS

1 Clone the repository

git clone https://github.com/ImXforever/fly-gold-trader.git
cd fly-gold-trader

2 Make setup executable and run

chmod +x setup.sh
./setup.sh

# To auto-start after install:
./setup.sh --run

3 Open dashboard

http://127.0.0.1:5000

Any OS Manual Setup

1 Create virtual environment

python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/Mac:
source .venv/bin/activate

2 Install dependencies

pip install -r requirements.txt

3 Configure environment

# Copy example config
cp .env.example .env

# Edit .env with your settings
# Key settings:
#   TRADE_MODE=paper    (paper = simulated, live = real money)
#   STRATEGY=ensemble   (uses all 7 strategies)

4 Start the server

python src/server.py
# Then open http://127.0.0.1:5000

Option 2: Deploy to Railway

1 Fork the repository

Go to github.com/ImXforever/fly-gold-trader and click Fork.

2 Create Railway project

Go to railway.app and:

  • Click "New Project"
  • Select "Deploy from GitHub repo"
  • Choose your forked repo

3 Add environment variables

In Railway dashboard, go to Variables tab and add:

TRADE_MODE=paper
STRATEGY=ensemble
PORT=5000
TYPESAFE_API_KEY=your_key_here    # Optional
FLY_ROOT=                         # Leave empty for simulated brain

4 Deploy

Railway auto-deploys on every push to main. Your app will be at https://your-project.up.railway.app.

5 Update .env for Railway

# In your repo's .env.example, Railway uses these from the Variables tab
# No file changes needed - Railway overrides .env with its own variables

Option 3: Deploy to Netlify

1 Fork the repository

2 Connect to Netlify

  • Go to app.netlify.com
  • Click "Add new site" > "Import from GitHub"
  • Select your fork

3 Build settings

Build command:    echo "deployed"
Publish directory: .

4 Note

Netlify serves static files only. The dashboard HTML works but the backend (trading, MT5) requires a server. Use Railway for full functionality.

Troubleshooting

Python not found

# Try python3 instead of python:
python3 --version

# Or use the full path:
/usr/bin/python3 --version

MetaTrader 5 not available

MT5 only works on Windows. On other platforms, the built-in SimBroker paper trading is used automatically. No action needed.

Fly brain falls back to simulation

This is normal. The real 166,700-neuron connectome requires the fly-wirehead data files. The simulated brain works identically for signal generation.

TypeSafe SDK not found

TypeSafe is optional. The ensemble strategies work without it. If you want TypeSafe Jev analysis, get an API key from typesafe.ai.

Port 5000 already in use

# Change port in .env:
PORT=8080

# Or use --port flag:
python install.py --port 8080 --run

Railway deployment fails

# Ensure these environment variables are set in Railway:
TRADE_MODE=paper
STRATEGY=ensemble
PORT=5000

# Check Railway logs for errors

Live trading warnings

LIVE mode trades real money. Always start with paper mode. Set appropriate risk caps. Never risk more than you can afford to lose.
