Welcome! The most advanced AI trading foundation is now yours. Follow each section in order to have your own RL trading engine, live dashboard, and professional indicators running in under an hour.

1. What’s Inside Your ZIP

gqr_institutional/
├── src/                 ← Python source (RL agent, backtester, API)
├── dashboard-ui/        ← React frontend
├── scripts/             ← Data preparation tools
├── configs/             ← Server & YAML configuration
├── tradingview_indicators/  ← 14 exclusive TradingView indicators (.txt, Pine v5)
└── tests/               ← Automated validation

2. Prerequisites

  • Python 3.10+ – runs the main engine
  • Node.js 18+ – needed only for the React dashboard
  • TradingView account (free) – to load the 14 GQR indicators
  • Docker (optional) – simplifies cloud deployment

3. Setting Up the Python Engine

Step 1: Terminal inside gqr_institutional folder.

Step 2: Create virtual environment:

python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows
.venv\Scripts\activate

Step 3: Install dependencies:

pip install -r requirements.txt

Step 4: Create required folders:

mkdir -p data/memory data/raw data/processed models/weights reports logs certs

Step 5: Configure environment:

cp .env.example .env

Edit .env (defaults work for simulation). Add Telegram/Discord tokens if desired.

Step 6: Run your first agent:

python -m src.main

You’ll see [XAUUSD] Agent initialised and Starting live loop.

4. Launching the Real‑Time Dashboard

Backend (API): In a second terminal:

uvicorn src.api.dashboard_server:app --host 0.0.0.0 --port 8000

Frontend (React): In a third terminal:

cd dashboard-ui
npm install
npm run dev

Open http://localhost:3000 — live equity, balance, drawdown & emergency stop.

Alternative: a Streamlit dashboard is included at src/monitoring/dashboard.py.

5. Running a Backtest (Historical Data)

Prepare: Place CSV files (time,open,high,low,close) in data/raw/.

Convert to Parquet:

python scripts/convert_csv_to_parquet.py --input data/raw --output data/processed

Pre‑compute SMC features (optional):

python scripts/precompute_features.py --input data/processed/XAUUSD.parquet --output data/processed/XAUUSD.features.parquet

Then run the backtester from your script/notebook using BacktestEngine.

6. Loading the 14 GQR Indicators into TradingView

Step 1: Log into TradingView (free account).

Step 2: Open Pine Editor (bottom panel).

Step 3: Copy & paste each .txt file from tradingview_indicators/ and click “Add to chart”.

Indicators include: Market Structure, Order Blocks, Breaker Blocks, Volume Delta, Adaptive SuperTrend, Money Flow Profile, Killzones, Liquidity Swings, Elliott Wave, and more.

7. Key Configuration (.env)

  • GQR_DATA_FEEDER_SYMBOLS – Assets to trade (default ["XAUUSD","EURUSD","DXY"])
  • GQR_RISK_MANAGEMENT_MAX_DAILY_RAWDOWN – 0.05 (5%)
  • GQR_RL_LEARNING_RATE – 0.00003
  • GQR_RL_TRAIN_EVERY_N_STEPS – 1024

8. One‑Click Docker Deployment (Cloud / VPS)

openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
   -keyout certs/server.key -out certs/server.crt \
   -subj "/CN=localhost"
htpasswd -c .htpasswd admin

Then run with docker-compose up -d.

9. Troubleshooting

ModuleNotFoundError: Activate venv and reinstall requirements.

Dashboard no data: Ensure python -m src.main is running.

Indicators not showing: Click “Add to chart” and check Pine console for errors.

Port in use: Change port in config or stop conflicting app.
