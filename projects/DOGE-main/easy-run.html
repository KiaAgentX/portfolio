 1. Quick Start – 3 Steps

 Step 1 – Unzip & Open Terminal

Unzip the package into a folder on your computer. Then open the terminal:

cd /path/to/your/unzipped/folder
# Example: cd ~/Downloads/DOGE_Vault_Premium_Edition_v3

On Windows, use cd C:\Users\YourName\Downloads\DOGE_Vault...

 Step 2 – Start Python Server

Run this single command:

python3 -m http.server 8000

You'll see: Serving HTTP on 0.0.0.0 port 8000

If python3 doesn't work, try python -m http.server 8000

 Step 3 – Open on Your Phone

On your phone (same Wi-Fi), open the browser and type:

http://192.168.x.x:8000/

Replace 192.168.x.x with your computer's IP address.

Find your IP: ifconfig (Mac/Linux) or ipconfig (Windows)

 4. Troubleshooting – Common Issues & Fixes

"python3 not found"

Install Python 3 from python.org or use python instead:

python -m http.server 8000

"Cannot connect from phone"

  • Ensure both devices are on the same Wi-Fi.
  • Check your firewall – allow port 8000.
  • Use the correct IP address (not localhost).
  • Try http://192.168.x.x:8000/ in your phone browser.
  • If using Windows, disable Windows Firewall temporarily (or add an inbound rule for port 8000).

"PWA not installing"

  • Make sure manifest.json is in the root folder.
  • Make sure service-worker.js is in the root folder.
  • Open the page via HTTP (not file://).
  • Clear browser cache and reload.
  • On iPhone, use Safari – PWA works best there.
  • On Android, use Chrome – tap the three-dot menu  Add to Home screen.

"Data not saving / localStorage empty"

  • Your browser must allow localStorage.
  • Check if you are in Incognito / Private mode – it doesn't save.
  • Clear browser cache but keep storage.

"All files missing after unzip"

  • Download the ZIP again from Etsy.
  • Use a proper unzip tool (e.g., 7-Zip, WinRAR, or built-in extractor).
  • Do not open the ZIP directly – extract it first.
  • Check that manifest.json, service-worker.js, and all HTML files are present.

"Simulator doesn't load / blank page"

  • Open the browser Developer Console (F12) to see errors.
  • Ensure all files are in the same folder.
  • Try opening index.html first, then navigate to the simulator.
  • Clear browser cache and reload.

"Server stops after closing terminal"

By default, the Python server stops when you close the terminal. To keep it running:

  • Mac/Linux: Use nohup or a terminal multiplexer like tmux.
  • Windows: Use start /B or run in a separate terminal.
  • For permanent use, deploy to a free platform like Netlify or GitHub Pages.

Yes – Python 3 is required for the local server. Download it from python.org.

If you can't install Python, use Netlify, GitHub Pages, or any other free hosting platform.

 Do I need internet to use the simulator? 

No – once loaded, all files work 100% offline.

The first load caches the files via the service worker. After that, you can use it without any internet connection.

 Can I use this on my phone without a computer? 

Yes – you have two options:

  1. Local server method: Run Python on a computer, then connect your phone via Wi-Fi.
  2. Hosted method: Upload the files to Netlify or GitHub Pages – then open the URL on your phone.

Both methods allow you to install the PWA on your phone.
