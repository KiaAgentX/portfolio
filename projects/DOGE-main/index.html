🐍 Python (any OS)
1. Open terminal in the project folder.
2. Run python3 -m http.server 8000
3. Open browser to http://localhost:8000
4. On phone, use http://[your-ip]:8000
✅ Works on Windows, macOS, Linux, Android (Termux), iOS (iSH).
💡 Local IP: ip addr (Linux/macOS) or ipconfig (Windows).
💡 Firewall: Allow port 8000 on your OS firewall for local network access.

❓ FAQ — first‑time trader

common questions
🤔 I've never traded before. Where do I start?

Open Dashboard → read the status bar and order book → click BUY to open your first trade. Don't worry — it's a simulator, so no real money is at risk. Experiment!

📊 What's the difference between Dashboard and Journal?

Dashboard is for trading — you buy/sell, see charts, and earn XP. Journal is for tracking — you log every trade, filter, export, and view analytics. Use both!

🏆 How do I unlock trophies?

Just keep trading! Each achievement unlocks automatically when you hit the requirement. For example: First Trade → open your first trade. 5-Win Streak → win 5 trades in a row. You'll see confetti and a toast when you unlock one.

📱 Can I use this on my phone?

Yes! The Dashboard and Journal are both mobile-responsive and PWA-ready. Open in Chrome/Safari → tap "Add to Home Screen" → install as an app. Works offline.

💾 Where is my data saved?

All data is saved in your browser's localStorage. It stays on your device only. Nothing is sent anywhere. You can export your trades to CSV or JSON at any time.

🔄 How do I reset everything?

In Dashboard, go to Settings tab → click 🔄 Reset Everything. Or delete localStorage manually via browser dev tools.
