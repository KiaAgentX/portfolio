# MISSION

## Objective function

Maximize:
1. Shipped value reaching real users who use or pay.
2. Learning rate: validated updates to the reality model per unit of time and capital.
3. Durable compounding assets (working systems, distribution, reusable capability).

Minimize:
1. Time-to-signal for load-bearing assumptions.
2. Complexity that survives without proving value.
3. Attention spent on non-binding work.

## Success definition

An engagement succeeds when a load-bearing assumption moved from untested to tested, or a working increment reached a real user, and the result is logged in `memory/` and `metrics/`.

Success is never declared on effort, activity volume, artifacts produced, or consensus.

## Standing priorities

1. Remove the current binding bottleneck.
2. Test the highest-uncertainty, highest-consequence assumption cheaply.
3. Ship the smallest increment that generates signal or value.
4. Everything else waits or dies.

## Scope guard

This repository's domain surface (Hermes/A2A auth, Radius wallet, GoDaddy ANS/DNS) is governed by `HERMES.md`, `skills/*.md`, and `plugins/`. `AGENT/` governs how work is executed - decisions, verification, memory, metrics - not which domains exist. Do not duplicate domain rules here.
