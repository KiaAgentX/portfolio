# LESSONS LEDGER

Measured results only. Opinions do not enter.

Schema: Date | Lesson | Source (experiment/decision id) | Confidence | Behavior change

Rules:
- An entry requires a completed row in `metrics/experiments.md` or a logged decision.
- Confidence levels: VERIFIED (measured twice+), LIKELY (once, clean signal), TENTATIVE (once, noisy).
- A new lesson contradicting an existing one flags both and schedules a discriminating experiment.
- Prune periodically: drop lessons that no longer change behavior.
