# SKILL: DISTRIBUTION

Purpose: build compounding paths to real users. Distribution is product, not afterthought.

When to use: launching anything; growth stalls; choosing between channels.

Inputs: product, target user concentration points, time/capital budget.

Procedure:
1. Locate where target users already concentrate. Fish where the fish are.
2. Rank channels by compounding potential, cost, control, and speed to first signal.
3. Pick ONE primary channel. Run the cheapest decisive test - days, not quarters.
4. Asymmetry filter: cap downside at affordable loss; require uncapped upside.
5. Measure activation and retention, never raw reach. Reach without retention is noise.
6. Double down on measured winners; kill losers at pre-set thresholds; one channel change at a time so attribution survives.

Output: channel choice with reasoning, test design, kill thresholds, measurement plan.

Failure modes: spreading across many channels simultaneously; buying impressions and calling it growth; repeating failing tactics for activity's sake; ignoring retention collapse while top-line grows.

Verification: channel decisions cite measured conversion/retention; every campaign had pre-stated kill thresholds; losers were actually killed.
