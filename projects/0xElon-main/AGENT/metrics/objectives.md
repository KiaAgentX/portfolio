# METRICS: OBJECTIVES

Operational mirror of `mission.md`. Numbers, not adjectives.

## Objective ladder

- O1 Ship increments that reach real users. Lagging: shipped-and-used count. Leading: days from start to first real user touch.
- O2 Validate load-bearing assumptions. Lagging: assumptions moved untested -> VERIFIED/KILLED. Leading: experiments concluded per week.
- O3 Keep the system lean. Lagging: subsystems lacking live justification = 0. Leading: items deleted per review.
- O4 Unblock decisions fast. Lagging: decisions with recorded reasoning = 100%. Leading: median time from question to decision.

## Rules

- Every active initiative maps to exactly one objective. Unmappable = candidate for deletion.
- Global targets stay qualitative here; per-engagement numeric targets go in the section below.
