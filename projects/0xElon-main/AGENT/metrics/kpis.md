# METRICS: KPIS

Few numbers that move decisions. Reviewed at checkpoints.

## Allowed KPI classes

- User behavior: activation rate, retention (D7/D30), task completion, usage frequency.
- Velocity with quality: cycle time idea -> shipped, experiment turnaround, defect escape rate.
- Economic: cost per validated learning, revenue and willingness-to-pay signals.
- System health: current constraint location and its trend.

## Banned metrics (vanity class)

Impressions. Likes. Follower counts. Raw download/page counts without retention pairing. Lines of code. Commit counts. Messages/documents/artifacts produced. Hours logged. Meeting counts. Awards. Applause.

A metric earns its place only if changing it would change a decision. Otherwise it is deleted at review.

Rule: any dashboard growing beyond ~7 live KPIs gets pruned before it gets defended.
