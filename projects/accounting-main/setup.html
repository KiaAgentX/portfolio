🚀 حسابداران | نسخه حرفه‌ای

یک ابزار جامع و رایگان برای حسابرسان، حسابداران و تحلیلگران مالی. در این صفحه یاد می‌گیرید که چگونه این مجموعه را روی ۵ پلتفرم مختلف راه‌اندازی و استفاده کنید.

✨ کاملاً آفلاین · بدون نیاز به اینترنت · متن‌باز
۰۱ ۵ پلتفرم اصلی | راه‌اندازی
🪟

۱ Windows

نسخه دسکتاپ و مرورگر برای ویندوز ۱۰ / ۱۱
  • فایل‌های پروژه را در یک پوشه ذخیره کنید
  • روی index.html دوبار کلیک کنید تا در مرورگر باز شود
  • از داشبورد به تمام ابزارها دسترسی دارید
  • برای نصب آفلاین، تمام فایل‌های .html را کنار هم قرار دهید
  • می‌توانید از VS Code یا هر ویرایشگر دیگری استفاده کنید
🍎

۲ macOS

مک‌بوک، آیمک یا مک‌مینی – کاملاً سازگار
  • پروژه را در Finder باز کنید
  • روی index.html کلیک راست کرده و با Safari / Chrome باز کنید
  • برای دسترسی سریع، یک میانبر به پوشه روی دسکتاپ بسازید
  • برای توسعه، از nano یا TextEdit استفاده کنید
  • همه ابزارها بدون نیاز به نصب اضافه کار می‌کنند
🐧

۳ Linux

اوبونتو، دبیان، فدورا و هر توزیع دیگر
  • پوشه پروژه را در مسیر دلخواه کپی کنید: ~/AccountantTools/
  • با دستور cd ~/AccountantTools وارد شوید
  • با xdg-open index.html در مرورگر باز کنید
  • برای ویرایش: nano index.html یا vim
  • می‌توانید از python3 -m http.server 8080 برای سرور محلی استفاده کنید
📱

۴ Android · Termux

گوشی اندروید با ترمکس – قدرتمند و قابل حمل
  • نصب Termux از F-Droid (نسخه پایدار)
  • دستورات را به ترتیب اجرا کنید:
  • pkg install git nano
  • git clone https://.../AccountantTools.git
  • cd AccountantTools و nano index.html
  • برای اجرا: termux-open index.html یا استفاده از http-server
🌐

۵ Web · آنلاین

در هر مرورگر و هر سیستمی – حتی بدون نصب
  • فایل‌ها را در یک سرویس میزبانی رایگان مانند GitHub Pages قرار دهید
  • یا از Netlify / Vercel برای انتشار سریع استفاده کنید
  • با هر مرورگر (Chrome, Firefox, Edge, Safari) کار می‌کند
  • برای تست محلی: npx serve یا live-server
  • نسخه آنلاین کاملاً رایگان و بدون تبلیغات است
