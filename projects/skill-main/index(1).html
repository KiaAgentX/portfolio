⚖️ مقایسه ۱۰ پرووایدر — کدام برای مرورگر مناسبه؟

همه APIها از مرورگر رفتار یکسانی ندارند. ستون «CORS» می‌گوید کدام‌ها بدون سرور واسط مستقیم از همین صفحه قابل تست‌اند. قیمت‌ها تقریبی per 1M tokens است.

پرووایدرمدل نمونهورودی / خروجی ($/1M) احراز هویتCORS مرورگر

⚠️ برای محصول عمومی همیشه تماس با API را از بک‌اند/پروکسی رد کن؛ کلید در مرورگر کاربر هیچ‌وقت امن نیست. این جدول فقط برای تست شخصی و نمونه‌سازی است.
