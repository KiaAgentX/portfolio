# 👔 راهنمای ادمین لانچ‌بات (v3 «دوزبانه»)

دو جای مدیریتی داری که هر دو به **یک دیتابیس** وصلن — هر کاری توی یکی بکنی، اون‌یکی همون لحظه می‌بینه.
هر دو هم **دوزبانه‌ان**: بات با `/lang`، وب با سوییچ 🇮🇷/🇬🇧 توی منو.

## ۱) مدیر بات تلگرام (با `ADMIN_IDS`)

اول به بات `/id` بده و عدد رو بذار توی `ADMIN_IDS` (بعدش Redeploy).

| دستور | کار |
|---|---|
| `/admin` | آمار (معوق‌ها، تیکت‌ها، کاربران) + لینک پنل وب |
| `/approvals` | صف تأیید سفارش/استعلام (دکمه ✅/❌ + ۳ دلیل رد) |
| `/tickets` | تیکت‌های باز + گفتگو + حل کردن |
| `/settings` | لیست همه‌ی متغیرها و مقدار فعلی‌شون (لیبل دوزبانه) |
| `/set <key> <value>` | تغییر متغیر — مثلاً `/set chat_model gpt-4o-mini` |
| `/set <key> -` | حذف اورراید = برگشت به پیش‌فرض (env) |
| `/lang` | تعویض زبان خودت (فارسی/English) |

نکته‌ها:
- هر ادمین نوتیف‌ها رو به **زبان خودش** می‌گیره؛ مشتری هم به زبان خودش.
- مقادیر عددی/اعتباری چک می‌شن (مثلاً `temperature` باید ۰ تا ۲ باشه).
- کلیدهای اتصال (`openai_api_key` و...) فقط از همین‌جا عوض می‌شن (توی وب نیستن چون حساسن) — با تغییرشون کلاینت LLM خودکار ریست می‌شه.
- متن خوش‌آمد و راهنما **به‌ازای هر زبان** جداست: `welcome_text` و `welcome_text_en` (همین‌طور `help_text` و `help_text_en`).
- کاتالوگ رو نمی‌شه با `/set` عوض کرد — از پنل وب.

## ۲) پنل وب (`/admin` با `WEB_PASSWORD`)

۱. `WEB_PASSWORD` و `WEB_SECRET` رو توی env ست کن (رمز قوی!).
۲. برو به `https://<app>/admin/login` و لاگین کن.
۳. حالا منو دو بخشه: لینک‌های **عمومی** + لینک‌های **ادمین** + سوییچ زبان.

| پنل | کار |
|---|---|
| داشبورد | آمار + آخرین معوق‌ها و تیکت‌ها |
| سفارش‌ها | تأیید/رد با دلیل (مشتری تلگرامی نوتیف می‌گیره، مشتری وب با کد پیگیری می‌بینه) |
| تیکت‌ها | دیدن ترد، پاسخ، حل کردن |
| 🧩 کاتالوگ | ویرایش نام/توضیح فارسی+انگلیسی، قیمت (خالی = استعلامی)، آیکون، حذف، افزودن خدمت — ذخیره در DB، همون لحظه توی بات هم اعمال می‌شه |
| ⚙️ تنظیمات | فرم همه‌ی متغیرهای بات (۱۴ تا، لیبل دوزبانه) — خالی = برگشت به پیش‌فرض |
| کاربران | لیست کاربران بات (حالت ویس/متن + مدل + **زبان** هرکس) |

## ۳) مشتری وب چطور پیگیری می‌کنه؟

بعد از ثبت سفارش/استعلام/تیکت، یه **کد** می‌گیره (`ORD-…` / `QOT-…` / `TKT-…`) — با همون کد از صفحه‌ی «پیگیری» وضعیت رو می‌بینه و روی تیکت گفتگو می‌کنه. کد مثل رمز عمل می‌کنه، پس جای امنی نگهش داره.

## ۴) چک‌لیست لانچ مدیر

- [ ] `ADMIN_IDS` ست شده و `/admin` جواب می‌ده
- [ ] `WEB_PASSWORD` قوی ست شده و `/admin` باز می‌شه
- [ ] Volume روی `/app/data` ساخته شده (وگرنه تنظیمات و سفارش‌ها با ری‌دیپلوی می‌پرن!)
- [ ] کاتالوگ از پنل وب ویرایش و ذخیره شده
- [ ] یه سفارش تستی → تأیید → نوتیف مشتری چک شده
- [ ] `/lang` و سوییچ زبان وب تست شده

## ۵) بازی حکم 🃏 (بدون نیاز به کانفیگ)

- کاربرها با `/hokm` در بات یا صفحه‌ی «🃏 حکم» در وب بازی می‌کنن (تو + گرگ 🐺 + یار 🤝 + روباه 🦊).
- حرف‌زدن ایجنت‌ها از همون `OPENAI_*` استفاده می‌کنه؛ اگه کلید نباشه جمله‌های آماده‌ی فارسی میاد (بازی هیچ‌وقت گیر نمی‌کنه).
- نکته: میز وب **مشترکه** (یه بازی برای همه‌ی بازدیدکننده‌ها) — نسخه‌ی شخصی با سشن مرورگر بعداً میاد.
- بازی‌ها در جدول `game_sessions` ذخیره می‌شن؛ با ری‌دیپلوی (روی Volume) چیزی نمی‌پره.
