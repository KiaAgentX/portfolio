📊 فرمول‌های کلیدی — برای حسابرسان

روش فرمول کاربرد
تصادفی ساده n = (Z² × σ²) / d² جوامع همگن و کوچک
سیستماتیک k = N / n جوامع بزرگ و منظم
طبقه‌بندی شده nᵢ = (Nᵢ / N) × n جوامع ناهمگن
MUS n = (N × Z × σ) / d حساب‌های پولی با ارزش
