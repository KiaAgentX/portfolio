# Kia Portfolio v1.0.0 — Official Desktop Release

First tagged release of the portfolio platform.

## Highlights

- **60 production projects** with **live previews (60/60)** and an in-site source viewer
- **Desktop app included** — `Kia-Portfolio-1.0.0-win-x64.exe` (portable, no install, full site bundled for offline use)
- **VALUATION.md** — independent triangulated valuation: fair value **~$758,565** (site claims $466,500 — deliberately conservative)
